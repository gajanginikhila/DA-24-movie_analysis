# Movie Analysis Project Using MySQL

## Project Overview
The Movie Analysis Project is a database management project developed using MySQL. It helps organize and analyze movie-related information, including movies, directors, actors, genres, ratings, and box office collections.

## Technologies Used
- MySQL
- MySQL Workbench

## Database Tables
1. Directors
2. Genres
3. Movies
4. Actors
5. Movie Actors
6. Ratings
7. Box Office

## SQL Concepts Used
- Primary Key and Foreign Key
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Views
- Stored Procedures
- Window Functions

## Project Objectives
- Store and manage movie information.
- Analyze movie ratings.
- Identify top-performing movies.
- Analyze box office collections.
- Generate reports using SQL queries.
